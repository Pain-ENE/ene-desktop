# ENE M0：DSH 本地接入验证报告

日期：2026-10-28。结论：固定版本的真实 DSH 已通过本机合成模型的基本接入验证。尚未验证云端模型、桌面程序、加密记忆、独立安全词或 computer use。

## 已实现

- 安装官方 npm DSH 与 Node SDK，版本均为 0.2.2-alpha.2，依赖锁定于 runtime/dsh/package-lock.json。
- ENE 外部适配器，通过 SDK 的公开接口启动独立进程，明确隔离的 DSH home 与工作区。
- M0 仅接受本机回环 HTTP 模型地址，不读取云端凭据；子进程使用受控环境和固定的合成凭据。
- 启动 patch 关闭模型可用的文件及命令执行工具，不通过模型自觉遵守来代替工具限制。
- 正常回复、会话恢复、错误上报、正在运行时停止及防止适配器自动重启。
- 本机 Messages/chat 合成接口、可重复的集成测试与落盘清单。

## 验证结果

最近一次 `node tools/verify-dsh.mjs`：2 个测试通过，0 失败。其中真实 DSH 集成测试包含以下 8 项行为检查：

| 检查 | 结果 |
| --- | --- |
| 本机合成服务返回指定文本，经真实 DSH 收到 | 通过 |
| SDK 会话事件及状态通知 | 通过 |
| 模型请求未携带可用工具列表 | 通过 |
| 关闭后新建运行时，恢复原会话及原提示上下文 | 通过 |
| 合成接口返回 503 时，适配器报错而不报告空字符串成功 | 通过 |
| 回复挂起期间停止运行时，原调用不能返回成功 | 通过 |
| 停止后同一适配器拒绝隐式重启 | 通过 |
| 在落盘目录发现已知合成原文标记 | 通过，证明当前尚未加密 |

本轮挂起回复的 SDK 停止测量为 27ms。这只是当前本机、无外部工具任务的合成场景测量，不是完整安全词性能承诺，也不证明任意外部程序都会在此时间内停止。

适配器还拒绝非回环模型地址；测试确认请求只携带合成凭据。真实 API 未调用，无真实模型 token 费用。

## 已查明的接口限制

官方 `deepseek-official` 在该版本使用 Messages 协议，本轮请求路径为 `/v1/messages`，不能把它简单当作任意 Chat Completions 网关。其他 API 服务商的接入需选取相应 provider 并验证。

当前观察到的 SDK 通知为 session.event、session.status；assistant/message 中保存本轮完整回复及流记录。尚未建立桌面可用的逐 token 实时增量通道，不能把收到事件宣称为已有逐字 UI。后续需验证扩展事件，必要时增加受控插件。

SDK 文档说明请求 timeout 不等于服务端取消。本适配器明确调用公共 close()，通过其 teardown 路径停止该运行时；独立于主 UI 的控制器、快捷键、语音安全词及完整进程树管理仍是 M1 工作。

当前软件索引未提供可安装的官方 Python SDK/运行时包，因此采用官方 Node SDK 验证，而不是使用 SDK 私有启动参数绕过公开接入约束。Python 桌面层的本地通信桥尚未实现。

## 落盘与隐私结果

测试目录在 runtime/test-runs/m0-*，均为合成数据。本轮实际发现匿名本机标识、profile 配置和 session.v4.jsonl。合成提示标记能从 JSONL 找到，故明确不具备记忆加密。

本轮没有图片/附件、shell 或 computer use 实际调用，不能据此认定这些路径无额外落盘。附件、请求图片缓存、spill、诊断及其他 provider 的写入仍需后续逐项验证。

所有测试运行使用新目录，未读取用户既有 DSH home，也没有创建正式 ENE 身份。原立绘和其他收藏未修改。

## 文件与重现

- adapters/dsh/runtime.mjs：外部适配器。
- adapters/dsh/ene-m0.cordis.yml：工具关闭及测试配置。
- tests/dsh/integration.test.mjs：真实运行时集成测试。
- tests/dsh/mock-model.mjs：本机合成服务。
- tools/verify-dsh.mjs、验证DSH接入.cmd：重现入口。
- runtime/dsh/m0-latest.json：最近实际证据，包含通过项、通知类型与落盘清单。

受限环境默认禁止子进程连接本机回环地址，最初出现 EACCES；在允许本机网络的执行环境复验后通过。这个环境限制不需要关闭 DSH 自身的工具限制。
