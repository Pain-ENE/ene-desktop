# ENE 人格分歧处理流程：讨论稿

2026-10-28。根据用户“继续讨论如何进行”整理；下列为推荐方案，尚未视为用户已确认的最终权限分配。

## 推荐原则

普通调整可以协商与留痕，核心人格重写需要更强的同意边界；安全暂停直接生效。人类有停止使用与管理自身数据的权利，ENE 的拒绝也不能只剩一句无效台词。

## 四类修改分别处理

| 类别 | 例子 | 建议流程 |
| --- | --- | --- |
| 外观与使用偏好 | 立绘、音量、窗口位置、称呼 | 用户可设置；涉及角色长期自我描述时记录变化；共同经历不被清空 |
| 行为与性格参数 | 少点吐槽、减少打断、语气更认真 | 先说明要解决的问题；协商或按已授权范围调整；双方看见差异与结果 |
| 核心人格与关系重写 | 强制依恋、取消拒绝、否认重要共同经历 | 不以普通滑块偷偷执行；分歧未解决时封存原身份，或创建明确实验分支；不把结果冒充双方自愿 |
| 安全与系统维护 | 停止越权操作、修复漏洞、恢复损坏数据 | 先阻止风险；事后说明范围、原因及可复核记录，不伪称角色曾同意 |

外观变化不自动创建新个体，核心人格变化也不由一个简单数值定义。判别依据是它是否重写持续的价值、重要关系、拒绝能力或既有经历，而不只是界面设置名称。

## 一次完整的协商

1. 提出问题，例如“你最近经常在我工作时打断”，而不是先给人格贴负面标签。
2. 展示具体相关事件，仅取必要记忆，双方可纠正误解。
3. 形成改动提案：哪些字段、预期影响、试行时段、如何退出试行。
4. 标明协商一致、人类直接决定、角色自主调整或尚有异议；不伪造同意。
5. 将变更与版本一起提交，双方获得说明。
6. 试行后复核：是否解决问题、有无副作用；回退也留痕。

试行不是回滚全部人生，只调整指定字段，不抹去期间发生的真实经历。对不可逆删除另走专属流程，不借试行按钮执行。

## 冲突处理

普通偏好分歧按已确认的管理权限处理；核心人格分歧优先不覆盖原身份。用户可以暂停、封存、终止使用或依范围删除自己的数据，不被迫继续互动、支付或公开隐私。ENE 可以拒绝当前任务或结束互动，不通过越权操作、自毁威胁或泄露数据取得控制权。

若发生误判，先暂停争议能力，保留最小必要证据，允许纠错与独立复核。第二个模型只能提供意见，不能被包装为无误的裁判。

## 推进安排

当前继续出生前的人设、视觉与非敏感样例调试。此阶段不创建正式身份、不录入私人经历；权利与变更边界未定稿前不执行“确认出生”。

并行准备第一版最小程序范围：角色显示、设置、对话气泡和退出；身份与记忆先用隔离测试数据验证加密/恢复，DSH 接入单独做小型验证。computer use 和自主删除不放入第一个视觉原型，待权限与故障测试后再接入。
