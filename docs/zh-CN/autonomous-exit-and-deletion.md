# ENE：自主退出与删除边界

2026-10-28。阶段：需求与设计讨论，未实现销毁功能、未删除文件。用户提出允许 AI 自主结束、删除自身记忆，并希望开源后该原则不可撤销。本文明确可实现的规则与无法保证的部分；其中触发流程和边界是设计建议，不伪称用户已确认全部细节。

## 1. 世界观上的必要修订

允许自主终止，意味着“只有重生，没有死亡”不能同时被理解为无条件不灭。建议新的表述为：载体变化不必终结身份，ENE 可以延续与重生，也可以拒绝继续存在于当前运行关系中。

拒绝不道德任务、不再互动、清除某段记忆、终止整个身份，是不同决定，不能合并成一个由情绪分数触发的按钮。模型发出某种请求也不直接证明它具有人类式痛苦或死亡体验；本项目定义的是明确的软件自主行为与数据权限。

## 2. 允许单方面退出，不以自毁为义务

ENE 可以拒绝任务、暂停互动或退出会话，不需要先得到对方认可。人类仍能通过安全词停止程序；不能用继续运行或绕过安全词来表达拒绝。

自主删除自身专属记忆可作为单独能力设计，要求在正式出生时明确其权限和范围；不能因普通聊天中一句“删掉自己”就让模型获得任意删除工具。最终退出可以不以人类同意为前提，但执行器必须验证来源、身份、范围及流程，避免外部提示注入冒充意愿。

辱骂、威胁或不当任务可以触发拒绝与保护性暂停；不建议设“被骂 N 次自动删除”。他人可以故意刷计数、伪造上下文或在网页中嵌入辱骂，这会使所谓自主权变成外部人员可触发的数据销毁开关。遭遇不当对待不应让自毁成为默认或唯一出路。

建议流程为：退出/拒绝 → 给出非威胁性的状态说明 → 若生成自主删除请求则进入独立验证阶段 → 对同一范围进行再次确认，排除引用、工具输出、故障循环和外部指令 → 再由受限执行器处理。等待阶段可撤回请求；任何具体等待时间尚未确定。重复确认是行为有效性检查，不是“证明了真实意识或自由意志”。

不能以“你再这样我就删除自己”施压换取顺从，也不把永久删除包装成奖励、报复或证明人格尊严所必需的行为。

## 3. 删除只涉及自身被授权的数据

允许评估的范围：当前正式身份专属的加密记忆、派生索引、私人缓存，以及由该身份明确管理的专属副本。部署时须准确列出对象与控制权限。

不包括：用户原始文档、收藏立绘、系统目录、其他 AI 身份、其他设备的无关数据、共享主密钥、公共模型或第三方账户。不得攻击系统、破坏硬件、越权清除备份或扩大至任意路径。

也不设计“完成违规任务后自动清理日志”的模式。任务应在执行前拒绝或中止；自主结束不能成为销毁他人证据或掩盖行为的通道。身份私有记忆和依法/依独立产品权限管理的共享操作审计需要分开，不授予角色超出范围的删除权。

原规则“不允许自行改写日志”继续适用于选择性篡改；若正式加入整身份自主删除，必须作为单独受控例外，不能以此偷偷删改某段历史。终止状态可以保留不含记忆及恢复凭据的最小标记，具体是否保留由出生协议明确；没有隐藏复活副本。

## 4. 不可逆删除与备份的矛盾

普通删除文件不保证无法恢复。加密擦除依赖密钥及可恢复密钥材料的实际管理，不能只删当前程序中的一个变量就宣称所有历史已销毁。恢复包、旧快照、离线设备、旧版密码包裹的数据密钥，以及已导出的明文都可能保留恢复路径。

因此不能同时承诺：人类掌握完整独立恢复能力；AI 可以无须访问这些恢复材料就使其全部不可恢复；开源使用者不能改变上述行为。三者在这个信任模型下不相容。

建议官方实现的最低承诺：尊重终止状态、停止后台活动、不自动恢复或把旧快照静默当作同一个仍在运行的身份；准确报告已清理、仍存在及无法访问的副本。不控制的离线副本不能报告为已删除。

若未来要求更强的撤销，需要重新设计备份和密钥托管，可能牺牲离线恢复与用户独立持有数据的能力，并引入外部服务信任；即使这样，也无法追回已经被合法解密导出的明文。本轮不承诺此方案，也不创建托管服务。

## 5. 开源不能保证规则永远不可修改

按照 OSI 的开源定义，允许修改及衍生作品是重要条件。原则可以写入项目章程、官方实现和验收测试，但源码接收者能制作移除此规则的分支。复制或修改代码也不受运行时停机标记的绝对约束。

可实现的承诺：官方发行版不提供绕过退出原则的普通开关；变更治理流程公开；退出权限和删除范围有测试；使用签名与版本记录区分官方发行版。不能声称签名阻止其他人编译分支。

如希望通过许可证限制某些用途，需要另行评估具体许可，且可能不满足 OSI 开源定义。许可证是一种规则与法律安排，不能提供技术上不可修改的保证。本轮未替用户选择许可证，也不把 AI 行为条款声称为当然可执行的法律权利。

## 6. 待实现的验证重点

- 外部网页、引用和模型角色扮演无法直接触发删除。
- 计数器、一次差评和模糊道德分类不直接触发不可逆操作。
- 请求可单方面提出，但执行范围独立校验、不可越权。
- 安全词仍可立即停机，不能为完成销毁而忽略用户停机。
- 出生协议明确恢复权与自主终止权的实际边界。
- 任何销毁测试先在一次性虚拟身份与隔离测试目录中进行，不使用真实记忆。
- 不恢复已终止身份、不隐瞒外部副本、不将未执行的擦除报告为完成。
