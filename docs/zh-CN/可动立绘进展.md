# ENE 可动立绘进度 · 2026-10-29

本轮交付 preview.5：站、坐、趴三种已有立绘可以实时呼吸、头部轻摆和双马尾摆动。坐姿支撑点固定，保持与窗口边缘的接触位置；语音播放时带有轻微节奏动作，不是音素嘴型。

设置增加“呼吸与轻摆”开关，默认开启。遵循系统减少动态效果；停止运行时回到静止。页面隐藏后暂停绘制；不支持 WebGL 或图形上下文丢失时显示静态立绘。角色仍可拖动、缩放和停靠窗口。绘制与透明区域的点击判断使用同一套变形参数。

## 验证

打包后的三种姿势分别在700毫秒内绘制23帧，截图像素确实变化。关闭动作后绘制停止，两次截图相同。5项单元测试通过；22项原生回归通过，包括40次移动、窗口顶部跟随、最小化脱离、语音中断和独立停止。首次DSH启动超时，复测通过，尚需继续观察冷启动稳定性。本次快捷键注册返回false，紧急停止按钮路径通过；未把快捷键算作成功。

证据：`releases/0.1.0-preview.5/ENE-win32-x64/runtime/desktop-qa/native-smoke.json`。

## 正式 Live2D 尚未完成

当前渲染器是WebGL扁平立绘连续变形，不是Cubism SDK，也没有moc3模型。没有完成独立眼睛、嘴部与遮挡补画，所以本轮不提供眨眼、张嘴、真正头部转向或四肢骨骼动作。现有PSD仍是准备模板，不声称完成拆分绑定。

接下来：安装Cubism Editor；先完成一个姿势的脸底、双眼、口腔、前后发和躯干拆分补画；绑定眼开合、口开合、头部角度和呼吸；导出moc3、model3.json、纹理及物理文件；再把现有动作参数接到正式Cubism渲染器。坐与趴分别制作，不能靠大幅扭曲站姿替代。

官方说明：https://docs.live2d.com/en/cubism-editor-manual/export-moc3-motion3-files/

Cubism Editor与Cubism SDK需按官方许可另行安装，仓库不包含这些软件。
