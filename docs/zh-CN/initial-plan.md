# ENE 桌面伙伴：产品与技术规划

> 本文为首轮规划。2026-10-28 起以《identity-memory-cross-platform.md》为主，覆盖跨平台、语音选型、加密、同步及开发顺序；本文保留素材盘点与初始研究记录。

日期：2026-10-28。阶段：资料调查与方案设计，尚未开发 EXE、下载语音权重、训练音色或生成最终角色素材。

## 产品定位

Windows 桌面常驻的 ENE 电子少女：有表情、会吐槽、能聊天，也能提醒和陪伴。最终以 ENE.exe 启动，提供便携包；需要安装版时另做 ENE-Setup.exe。收藏立绘按用户指定仅用于本地非商业项目，不上传到公开素材库。

默认方向：ENE 蓝色电子形态、中文对话、中文 TTS，保留可切换的日语发声。AI 对话与 TTS 分别配置，可以独立更换。首版先让角色、交互和语音稳定，再增加复杂动画。

## 研究结论与创作边界

官方确认：ENE 是目隐团 No.6，原名榎本贵音；电子形态住在伸太郎电脑里，天真活泼，热衷捉弄他；日语配音为阿澄佳奈。其原人类身份与电子形态应区分。

“毒舌、傲娇”是本产品依照用户偏好做的演绎。建议以电子形态的活泼、恶作剧、对电脑环境的熟悉为核心，加入嘴硬、好胜和不直说的关心。贵音的详细性格及跨媒介差异，后续通过原作进一步核对；不把未经核实的同人设定写成官方事实。

角色表达规则：

- 吐槽具体行为，随后回应需求；用户认真提问时，信息准确优先。
- 日常回复短一些，通常 1—3 句；用户需要分析时允许展开。
- 可以装得意、假装嫌弃、否认关心，但不能每句话都套“才不是……”。
- 用户低落或明确不喜欢时降低毒舌强度；不以用户脆弱处反复取乐。
- 不声称看到了未授权的屏幕、文件、摄像头或聊天记录。
- 恶作剧通过动画与台词实现；不删除文件、移动真实窗口或自行发送消息。
- 默认称呼“主人”，支持改名；中文“主人”属于本地化选择。

原创示例：

- 启动：“连接成功。主人，你的桌面还是这么有个人风格啊……好啦，我回来了。”
- 拖动：“喂——我是电子生命，又不是桌面快捷方式！”
- 求助：“卡在这里了？把报错给我看看。哼，总不能让你对着它发呆一晚上。”
- 夸奖：“现在才发现我很厉害？……再说一次也不是不行。”
- 疲惫：“先休息一下吧。我又不会趁你离开就消失。”

对 141 张单人图进行了可读性与透明通道检查，均可读取。仅 651_754953.png 检出 alpha=0 的像素，但目视为贵音主题画作，带大面积排版与背景，不是可直接用的 ENE 透明立绘。其余部分 PNG 有轻微半透明，不等于背景已去除。本地未发现 wav/mp3/flac/ogg/m4a 音频。

视觉路线：先选一张轮廓完整、面部清晰、蓝色双马尾、耳机、蓝色宽大外套的电子形态作为唯一主参考；保留其画风与服饰。先制作主图去背景样张及六个表情的对照预览，核对后再做最终素材。原收藏保留原样，衍生素材独立存放并记录来源。

首版表情：正常、得意、嫌弃、害羞、关心、困倦。交互状态：待机、被触碰、被拖动、思考、说话、安静。表情和状态分开组合。没有分层素材时，以轻微浮动、位移和表情切换为主；眨眼、口型需额外准备面部图层，不能把静态插画当作现成 Live2D 模型。

界面：默认停在桌面右下，高约 280—360 逻辑像素，可缩放；对话气泡用深蓝、青色与少量白色。设置集中在托盘菜单，角色本体保持简洁。呼吸和浮动要克制，提供完全静止模式。

## 第一版功能

1. 透明无边框窗口、置顶开关、拖动、缩放、位置记忆、多屏和 DPI 适配。
2. 气泡对话、点击反馈、六种表情、托盘菜单、隐藏/显示快捷键、可靠退出。
3. 文字聊天、流式回复、停止生成、短期上下文和可清除的本地历史。
4. TTS 开关、音量、语速、停止播报；音频失败时保留文字回复。
5. 手动设置提醒、休息提醒、安静时段；主动发言有冷却时间和关闭开关。
6. 离线固定台词，使未配置模型或断网时仍能作为桌宠使用。

后续加入：按键说话、语音识别、明确授权后的屏幕上下文、可编辑长期记忆、贵音皮肤、Live2D。首版不默认持续录音或读取屏幕。

## 技术路线

推荐 Python + PySide6 / Qt Quick 构建 Windows 桌面壳，使用 pyside6-deploy / Nuitka 打包。Qt 支持透明窗口，Windows 需配合无边框窗口标志；官方部署工具支持 Windows EXE 及单文件模式。

模块分离：桌面壳 → 行为控制器 → AI 接口适配器 / TTS 适配器 → 音频播放器。角色素材管理、SQLite 本地历史和设置模块独立。

AI 返回文本及受约束的情绪标签，例如 neutral / smug / annoyed / shy / caring / sleepy；客户端校验后映射表情。模型输出不直接转为系统命令。动画、窗口响应和网络请求异步运行，防止聊天时拖不动角色。

对话后端先接兼容 HTTP 对话接口的云端服务，可更换地址、模型和凭据；本地模型作为可选后端。云端收到哪些内容应在设置中清晰说明。API 密钥存入 Windows 凭据存储，不写入源码、分发配置或日志。

已检测设备：NVIDIA GeForce RTX 4080 Laptop GPU，显存 12282 MiB。具备评估本地 TTS 的条件；不保证某模型在当前环境下的速度或显存余量。优先云端对话 + 本地 TTS，避免本地大模型与 TTS 同时争用显存；后续按实测决定完全离线组合。

## TTS 与音色初始化

查证到原角色声优，但本轮没有取得并试听原声文件；以下是待试听校准的声音设计目标，不是对已测声学参数的结论：明亮年轻女声、清晰靠前的发音、偏快且有停顿变化，吐槽时带笑意，关心时降低强度。中文发音自然度和日语角色相似度分别评估，不能保证日语参考可无损迁移到中文。

首选评估 GPT-SoVITS：官方提供 Windows 整合包，支持中文和日语、参考音频合成和少样本微调，便于后续做角色专用声音。备选 Qwen3-TTS：官方提供中文/日语、声音设计与参考音频克隆；使用不同能力对应的模型，不能假定所有模型都同时支持同一种情绪控制。

本轮搜索未找到来源、可用性及授权均可核验的 ENE 专用现成模型，暂不下载来历不明的权重。图像的使用范围不自动延伸到声音训练素材；项目保持本地非商业，音频来源及允许用途单独记录。

初始化流程：

1. 从用户可提供的原声素材或可使用的来源确定参考片段，记录出处。官网角色页带 MOVIE 入口，可作为核对角色演绎的起点；本轮直接访问受限，未确认当前播放器是否可用。
2. 先取数段短而干净的独白作为试听参考，分别覆盖普通、得意、吐槽、关心；避免多人重叠、强背景音乐、喊叫和唱歌。
3. 保存无损参考音频与逐字文本，按所选引擎要求转换采样率，核对日语转写。
4. 用同一组中文、日语测试句比较两条路线，记录发音、音色稳定性、情绪、首音延迟、整句耗时和显存峰值。
5. 确定一个主声音并缓存常用台词；必要时增加数分钟经清理标注的素材做微调，数据量以效果决定。
6. 保存 voice_profile、参考音频路径、文本、模型版本与设置。没有参考音频时保持 reference_required 状态，不能标为初始化成功。

TTS 与 AI 文本按句衔接，允许中断，避免每个字单独送去合成。普通提示音与短台词预缓存。首版嘴部变化可依音量驱动，但需要已有开闭嘴素材；严格音素口型留待后续。

## EXE 交付形态

推荐 ENE.exe + assets/ + 可选 models/ 的便携目录，用户解压后双击启动。若要求单个分发文件，提供安装 EXE 或单文件桌面壳，模型首次启用时下载到本地缓存。

大体积语音权重与 CUDA 运行时独立管理，按需启动 TTS 子进程，并允许闲置释放显存。内置运行环境，日常运行无需用户手工启动 Python。最终体积以选定引擎及实际构建结果为准，不在规划阶段承诺几十 MB 或固定响应速度。

## 实施里程碑与验收

| 阶段 | 交付 | 通过条件 |
| --- | --- | --- |
| A 形象与性格 | 主形象对照、表情草图、人设文件、示例台词 | 角色一致，毒舌强度合适，区分 ENE 与贵音 |
| B 桌面原型 | 可运行桌宠与首个 EXE | 透明、拖动、缩放、托盘、多屏可用，退出无残留 |
| C AI 对话 | 可配置后端、流式聊天、本地历史 | 回复不中断界面；断网、超时、取消可恢复 |
| D 声音 | 同句 A/B 试听、voice_profile、播放与中断 | 中文可懂、日语自然、音色稳定；公开实际延迟与显存 |
| E 最终交付 | 便携包或安装 EXE、配置指南、素材来源清单 | 无开发环境可启动，密钥不随包泄露，空白配置也可退出 |

工作量取决于主形象能否直接分层、是否已有干净原声、音色试听结果。先完成 A/B 两项可以尽早确定它是否有 ENE 的感觉，避免把时间都花在更换模型上。
